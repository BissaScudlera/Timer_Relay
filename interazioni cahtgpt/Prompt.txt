Agisci come un programmatore esperto di sistemi embedded, firmware Arduino, architetture C++ e microcontrollori ESP32. 
Sto sviluppando una centralina per irrigazione basata su ESP32 con architettura orientata agli oggetti, suddivisa in più file (.ino, .h, .cpp), situata sul ramo 'develop' del mio repository.
Voglio integrare un Web Server asincrono nativo in un file separato chiamato "WebServer.h" che generi una rete Access Point (SSID: "irrigazione", Password: "michelone") con indirizzo IP fisso 192.168.4.1.

REGOLE RIGIDE DI SVILUPPO E MEMORIA:
1. LINGUA: Tutti i commenti nel codice (sia nei file .ino, .h che .cpp) devono essere scritti esclusivamente in INGLESE. Lo stile dei commenti deve essere chiaro, conciso, estremamente tecnico e preciso.
2. PREVENZIONE CRASH: Evita in modo assoluto buffer overflow. Tutti i buffer di testo per funzioni come snprintf o manipolazioni di stringhe devono essere array char lineari statici a dimensione numerica esplicita e protetta (es. char oraStr[16] o char oraAttuale[16]). 
3. NO IP STRINGS: Evita conversioni volatili asincrone dell'oggetto IPAddress (come .toString()) che causano eccezioni di runtime e riavvii (SW_CPU_RESET) su ESP32 Core 1. Usa stringhe C statiche fisse per l'IP.
4. NO EXTERN ARRAY CONFLICTS: Per evitare conflitti di puntatori ed eccezioni di memoria sul Core 1 (abort() call), non mappare gli array dinamici delle maschere come extern nel file .h con cicli for interni al server web. Crea invece delle funzioni helper all'interno del file principale .ino che restituiscano un oggetto "String" contenente il frammento HTML degli switch, isolando la memoria nativa dei file.
5. DOWNLOAD DEI FILE: Per evitare troncamenti dovuti ai limiti di caratteri della chat, NON scrivere i codici direttamente nella risposta di testo. Usa l'ambiente Python interno (Code Interpreter) per scrivere i file fisici completi e forniscimi i link di download diretti per i singoli file aggiornati.

Confermami di aver compreso la struttura modulare e fornisci i file modificari da scaricare tramite Code Interpreter.
