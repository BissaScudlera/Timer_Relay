Agisci come un programmatore esperto di sistemi embedded, firmware Arduino, architetture C++ e microcontrollori ESP32. 
Ho ristrutturato completamente il progetto del mio temporizzatore/centralina per irrigazione. Trovi l'intero ecosistema sul ramo 'develop' del mio repository pubblico: https://github.com/BissaScudlera/Timer_Relay/tree/develop

Per consentirti di analizzare i flussi, le dipendenze hardware e coordinare le modifiche senza creare bug di compilazione, ti allego qui sotto il codice sorgente completo di tutti i file attivi del mio firmware. Leggili con attenzione.

Ho bisogno che tu assimili questa struttura modulare. Segui rigorosamente queste direttive per ogni modifica futura:
1. I commenti nei file  devono essere scritti in INGLESE.
2. I commenti devono essere chiari, precisi e concisi, tecnici.
3. Evita in modo assoluto buffer overflow (alloca buffer espliciti di dimensioni fisse come char buffer[16] per snprintf o manipolazioni di stringhe) ed evita conversioni asincrone volatili dell'oggetto IPAddress che causano eccezioni di runtime e riavvii (SW_CPU_RESET) su ESP32.
4. Per evitare troncamenti e perdite di codice dovuti ai limiti di caratteri della chat, non scrivere i blocchi di codice direttamente qui. Usa invece l'ambiente Python interno (Code Interpreter) per scrivere i file modificati e forniscimi i link di download diretti per i singoli file aggiornati.

Confermami di aver compreso la nuova architettura orientata agli oggetti dei file allegati e riassumi brevemente quali istanze dei vari manager (es. RTC o I2C) vengono passate o condivise con il WebServer.h.
